# 寫作參考

Version 4.1.0 | Updated: 2026-10-23

供人／Agent 協助整理內容時參考。作者有空時發文，自行篩選內容並決定發布時機；文章不設固定頻率、字數、章節結構或語言格式要求。

發文操作見 [Development](../DEVELOPMENT.md#建立內容)，可直接複製[基本範例](../_posts/2025-10-23-pixel-art-intro.md)或[含圖片範例](../_posts/2025-10-24-ai-tools-guide.md)。範例提供用法，不限定文章寫法。

## 內容方向

分享 AI 工具、技術實戰、數據應用與學習心得，以繁體中文降低理解門檻。專案定位與範圍見 [README](../README.md#目標與範圍)。文章可以是短筆記、長篇教學或個人經驗，不必套用固定格式。

## 寫作時可參考

以下是編輯建議，依文章需要取用，由作者判斷取捨，不作為發布檢核門檻：

- 讓標題與開頭表達文章想分享的問題、經驗或收穫。
- 有操作步驟時，補充讀者需要的背景、環境與結果。
- 技術範例可說明版本、依賴與執行結果；示意片段與實測結果應分清楚。
- 有需要時加入圖解、相關連結與參考來源，協助閱讀與查證。
- 技術詞可使用英文或常用中文，文章程式註解可依讀者需要使用中英文。

## Agent 協助方式

依作者當次需求協助整理、校對或查核，保留原意與語氣；不為符合範本擴寫、不要求湊字數或增加固定章節，也不安排未經要求的發文排程。內容取捨與是否發布由作者決定。

儲存庫程式與註解仍遵循 [agents](../agents.MD#實作品質)；這與文章教學範例的語言選擇分開。

## 網站使用方式

文章欄位、分類／標籤、圖片與網址仍依 [Development](../DEVELOPMENT.md#建立內容)及現行模板使用。正文從 H2 開始可避免與版型主標題重複，這是顯示方式，不要求文章採固定章節。

圖片處理見 [Development](../DEVELOPMENT.md#圖片處理)；語法高亮、複製與相關文章等由模板處理，不需在正文自行實作。視覺約束仍見 [Design System](DESIGN_SYSTEM_SPEC.md)。

舊字數、排程、固定結構與語言規則已依作者決定退出現行要求，決策與歷史來源見[整理紀錄](superpowers/plans/2026-10-23-documentation-reorganization.md#15-作者決策自由寫作與不定期發文)。
